# Prototyp ekonomického modulu

[`index.html`](index.html) je klikací prototyp ukázaný PO 25. 11. 2026 ([zápis](../../zapisy/2026-11-25-sprint-5-planning.md)), upravený 26. 11. podle rozhodnutí D-210 až D-217. Soubor otevřete v prohlížeči; obnovení stránky vrátí výchozí data. Všechna data jsou vymyšlená.

Tři akce (šipka zpět vede na seznam): Letní kemp Lipno (běží přihlášky), Zimní kemp Šumava (před přihláškami), Podzimní kurz jógy (bez ubytování).

Prototyp ukazuje chování, ne finální vzhled. Když se liší od ticketu nebo [registru rozhodnutí](../../rozhodnuti/README.md), platí ticket a registr. Známé odchylky:

- Počítá s jednou cenou za akci; v aplikaci má cenu každý termín (D-216).
- Kategorie jsou napevno a nákladové položky nejde přidat ani smazat.
- Ostatní záložky akce jsou jen ozdoba.
